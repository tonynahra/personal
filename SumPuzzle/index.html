How to Play

  • This is an addition puzzle: Number 1 + Number 2 = Result.
  • Digits (0-9) are replaced by letters.
  • Each letter represents a unique digit.
  • Click the numbers to guess the value of the highlighted letter.
  • Solve it before the timer runs out!

Scoring System

  • Correct Guess: +100 Base Points.
  • Time Bonus: The faster you solve, the higher the multiplier.
  • Penalty: Wrong guess reduces score.
  • Hint: Reveals one letter but costs 50 points.
  • Failure: Giving up or time out lowers difficulty.
